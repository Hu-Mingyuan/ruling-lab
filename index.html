Two independent command-line programs for convex lattice polygons.

Direct ruling counter

Count disk and annular rulings in each genus. Requires Python 3.10+ and Node.js 18+.

Download ruling ZIP README & source

Refined tropical tree counter

Compute the refined tropical polynomial from fixed boundary moments, then optionally compare it with ruling counts. Requires Python 3.10+.
